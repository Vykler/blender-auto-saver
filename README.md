
# Blender Auto Saver by Vyke

Automatically saves your `.blend` file at custom intervals and displays the save duration directly under the animation timer. Perfect for artists and animators who want to protect their work without breaking focus.

---

## 🔧 Features

- ⏱ Auto-saves .blend files every 1–60 minutes
- 📁 Uses Blender’s native save system
- ⏳ Displays how long the last save took
- 🎞 Save notifications appear under the animation timeline
- 🛡 Helps prevent work loss due to crashes or power cuts
